# Explore Local Statistics app rebuild

**Important: This repo is now archived. Progress has been merged into the main [explore-local-statitics-app](https://github.com/ONSdigital/explore-local-statistics-app) repo.**

-----

This repo contains in-progress work on a rebuild of the [Explore Local Statistics](https://www.ons.gov.uk/explore-local-statistics/) (ELS) app. The latest working demo of the rebuild can be [explored on Netlify](https://els-api-poc.netlify.app/).

The primary purpose of the rebuild is to improve data loading performance through the development of a new internal data structure and API, but it also includes a number of small design and code enhancements. The premise of this work is [explained here](https://github.com/ONSdigital/els-api-poc/blob/main/BACKGROUND.md), and the internal API is documented in [this wiki](https://github.com/ONSdigital/els-api-poc/wiki).
